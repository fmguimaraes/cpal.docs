# cpal.docs

Single source of truth for c-PAL's requirements, specs and process. Tickets
and code reference these docs by id and link; they never copy requirement
text (see [`sdlc/README.md`](sdlc/README.md)).

## Start here

- [Architecture](architecture/README.md) — what the system does, its
  components and stack, how they connect.
- [Features](features/) — feature specs (W1), e.g.
  [Pharma demo dataset tooling](features/pharma-demo-dataset.md).
- [SDLC](sdlc/README.md) — repo topology, delivery workflow, git
  conventions, Review Gate.
